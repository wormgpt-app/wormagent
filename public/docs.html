Intro

WormAgent is an open source coding agent. It’s available as a terminal-based interface, desktop app, or web app.

curl -fsSL https://wormagent.net/v2/install | bash
brew install wormgpt-app/tap/wormagent-v2
npm install -g @wormagent/cli
bun install -g --trust @wormagent/cli
pnpm add -g --allow-build=@wormagent/cli @wormagent/cli
yarn global add @wormagent/cli
vp install -g @wormagent/cli
paru -S wormagent-beta
mise use -g wormagent

The npm package uses a postinstall script to select the native wormagent binary for your platform. The Bun and pnpm commands explicitly allow the required script; Vite+ requires no additional flag. The mise command requires mise 2026.10.9 or later; older versions install WormAgent 1.

Windows package managers are not supported.

Download a standalone CLI binary for your platform.

  • macOS: Apple silicon · Intel · Intel (baseline)
  • Windows: ARM64 · x64 · x64 (baseline)
  • Linux (glibc): ARM64 · x64 · x64 (baseline)
  • Linux (musl): ARM64 · x64 · x64 (baseline)

Download the latest WormAgent Desktop build for your platform.

  • macOS: Apple silicon · Intel
  • Windows: x64 · ARM64
  • Linux (.deb): x64 · ARM64
  • Linux (.rpm): x64 · ARM64
  • Linux (AppImage): x64 · ARM64

Access the WormAgent web interface with the wormagent pair command.

Terminal
$ wormagent pair

  Open a link to connect. Links work once and expire in 5 minutes.

  http://127.0.0.1:49374/auth/connect/...

Docker images use versioned tags, for example ghcr.io/wormgpt-app/wormagent:2.0.0.

WormAgent has built-in support for many LLM providers. You can connect to them directly in the TUI with /connect.

See Providers to configure custom providers.

If you’d like easy access to the best coding models, you can try out WormAgent Console.

You can also try WormAgent Go, a $10/month subscription plan that grants you access to the best coding models.

Make WormAgent your own by editing the WormAgent config, loading plugins, connecting MCP servers, or creating commands. For terminal interface themes and keybindings, see CLI settings.

If you are interested in an in-depth course on WormAgent, Boot.dev has created an excellent AI Coding with WormAgent course in consultation with our team. All the information in the course is free to read and watch, though some interactive features may require payment.
