Product|Desktop

Desktop

Run several agents at once, each session in its own tab. Review every change as a diff, comment on any line, and check the result in the built-in browser. For macOS, Windows and Linux.

Download

Features

Parallel agents

Start as many agents as you want and let them all work in parallel. Jump between them as they finish.

See it in the browser

Your app opens in a browser beside the agent, so you both see every change land.

On every device

Start agents across all your devices, and pick them up from the desktop app, the terminal or your phone.

Extend it

Connect your tools and services so the agent can work with anything. Or have WormAgent build plugins for itself, with their own UI in the sidebar.

  2. Nov 18, 2026v2.3.1

    Compaction Without the Wait

    As a session nears automatic compaction, the summary is now written in the background, so your next prompt doesn't pause for it. Set compaction.background: false to turn it off; a background summary that ends up unused still costs tokens.#64290

    Update Plugins from Settings

    Open Settings › Extensions, click Check for updates, then Update on any plugin with a new version.#64511

    Comment on Selected Code

    Selecting code in diff and file viewers now just selects it, so you can copy it, and an Add comment toolbar appears beside the selection.#64410

    WormAgent 1 now offers the upgrade to WormAgent 2.0
