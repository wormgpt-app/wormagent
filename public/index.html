WormAgent — The open source
coding agent

يعمل على جهازك، مع أي موديل من 200+ مزود (Claude, GPT, Gemini...). سريع، مفتوح المصدر (MIT)، ويعمل على Desktop و Terminal و Mobile و SDK.

⚡ التثبيت — سطر واحد

curl -fsSL https://wormagent.net/install | bash
يُثبّت wormagent في ~/.wormagent/bin ويضيفه للـ PATH تلقائياً.

v2 (موصى به)

curl -fsSL https://wormagent.net/v2/install | bash

v1

curl -fsSL https://wormagent.net/v1/install | bash

📦 npm / bun

npm i -g @wormagent/cli # أو bun add -g @wormagent/cli

🪟 Windows (PowerShell)

irm https://wormagent.net/install | iex

▶️ التشغيل

wormagent wormagent --help wormagent --version
