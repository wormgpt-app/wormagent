[Hermes Agent](https://hermes-agent.nousresearch.com) includes WormAgent providers for pay-as-you-go and Go. It picks the
right API for each paid or Go model. Free-tier chat models require WormAgent and return HTTP `403` from Hermes.

<Callout>
  The [Console CLI](/console/harnesses#console-cli) sets up Hermes with one command, including the workspace's policies,
  MCP servers, skills and instructions. Run `npx @wormagent/console setup hermes`. The steps below set it up by hand.
</Callout>

| Provider       | Plan          | Key variable           |
| -------------- | ------------- | ---------------------- |
| `wormagent-zen` | Pay-as-you-go | `WORMAGENT_ZEN_API_KEY` |
| `wormagent-go`  | Go            | `WORMAGENT_GO_API_KEY`  |

## Configure

Run the model setup and select **WormAgent Zen** for pay-as-you-go or **WormAgent Go** for Go.

```bash
hermes model
```

Paste a [personal API key](/console/harnesses#get-an-api-key), then choose a model. Hermes saves the
key to `~/.hermes/.env` and the selection to `~/.hermes/config.yaml`.

```yaml title="~/.hermes/config.yaml"
model:
  provider: wormagent-go
  default: kimi-k3
```

<Callout>Go requires a session ID on every request. Hermes v0.21.6 and later send it automatically.</Callout>

## Models

Use model IDs from the [Console](/console/models#endpoints) or [Go](/console/go#endpoints) table without a prefix.
Switch models in a session with `/model`, or pick one for a single run.

```bash
hermes chat --provider wormagent-zen --model claude-sonnet-5-5
```

## Console MCP

Add the [Console MCP](/console/harnesses#console-mcp) server with OAuth, then sign in from the browser.

```bash
hermes mcp add wormagent-console --url https://wormagent.net/console/mcp --auth oauth
hermes mcp login wormagent-console
```

Or add it to `~/.hermes/config.yaml` and run `/reload-mcp` in a session.

```yaml title="~/.hermes/config.yaml"
mcp_servers:
  wormagent-console:
    url: https://wormagent.net/console/mcp
    auth: oauth
```
