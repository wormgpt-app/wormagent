---
title: "CLI commands"
description: "Reference for the wormagent command line."
---

Every command accepts `--help` for its full flag list, for example `wormagent run --help`. Some server-backed commands accept `--standalone` to run a private server or `--server <url>` to target a specific one; check the command's help for its supported flags.

## run

Sends a message and prints the reply without opening the interactive interface.

```bash
$ wormagent run "Explain this repository"
```

### CI

In CI, pass a provider API key as a secret and use standalone mode so the private server receives it. For example, this GitHub Actions job reviews the checked-out repository:

```yaml
name: WormAgent review
on: [pull_request]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install --global @wormagent/cli
      - run: wormagent run --standalone --model anthropic/claude-sonnet-5-5 "Review this repository for correctness and summarize any issues."
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
```

Choose a model.

```bash
$ wormagent run --model anthropic/claude-sonnet-5-5 "Refactor parseToken"
```

Continue the last session.

```bash
$ wormagent run --continue "Now handle the expired case"
```

Emit newline-delimited JSON for scripts.

```bash
$ wormagent run --format json "List the TODO comments"
```

Attach files to the message.

```bash
$ wormagent run --file src/server.ts --file src/client.ts "Review these for bugs"
```

Run with a specific agent.

```bash
$ wormagent run --agent build "Fix the failing test"
```

Continue a specific session.

```bash
$ wormagent run --session ses_4f2a1c "Check edge cases"
```

Auto-approve permissions that are not explicitly denied.

```bash
$ wormagent run --auto "Fix the failing test"
```

Create the session archived so scripted or CI runs stay out of session lists and the inbox. The session still exists: `wormagent session list` includes it, and you can open it by ID.

```bash
$ wormagent run --archived "Review this diff"
```

View all subcommands and flags.

```bash
$ wormagent run --help
```

## mini

Starts the minimal interactive interface instead of the full-screen TUI.

```bash
$ wormagent mini
```

Continue the last session.

```bash
$ wormagent mini --continue
```

Start with a model and an initial prompt.

```bash
$ wormagent mini --model anthropic/claude-sonnet-5-5 --prompt "Summarize this repository"
```

Continue a specific session.

```bash
$ wormagent mini --session ses_4f2a1c
```

View all subcommands and flags.

```bash
$ wormagent mini --help
```

## session

Manages sessions.

```bash
$ wormagent session list
```

Limit the list and print JSON.

```bash
$ wormagent session list --max-count 20 --format json
```

Delete a session and its child sessions.

```bash
$ wormagent session delete ses_9c1b08
```

Export session data as JSON.

```bash
$ wormagent session export ses_4f2a1c
```

Redact sensitive transcript and file data when exporting.

```bash
$ wormagent session export ses_4f2a1c --sanitize
```

Import session data from a JSON file or URL.

```bash
$ wormagent session import session.json
```

Import into a specific directory.

```bash
$ wormagent session import session.json --directory ~/code/project
```

View all subcommands and flags.

```bash
$ wormagent session --help
```

## auth

Manages AI providers and credentials.

```bash
$ wormagent auth list
```

List them as JSON.

```bash
$ wormagent auth list --format json
```

Log in to a provider.

```bash
$ wormagent auth login anthropic
```

Log in with a specific authentication method.

```bash
$ wormagent auth login anthropic --method key
```

Log out of a saved account.

```bash
$ wormagent auth logout anthropic work
```

Switch the active account for an integration.

```bash
$ wormagent auth switch anthropic work
```

Export saved credentials and import them on another machine. The file contains secrets.

```bash
$ wormagent auth export anthropic > credentials.json
$ wormagent auth import credentials.json
```

View all subcommands and flags.

```bash
$ wormagent auth --help
```

## mcp

Manages MCP (Model Context Protocol) servers.

```bash
$ wormagent mcp list
```

Add a remote server.

```bash
$ wormagent mcp add context7 --url https://mcp.context7.com/mcp
```

Add a local server to the global config.

```bash
$ wormagent mcp add everything --global -- npx -y @modelcontextprotocol/server-everything
```

Add a local server with an environment variable.

```bash
$ wormagent mcp add everything --env LOG_LEVEL=debug -- npx -y @modelcontextprotocol/server-everything
```

Add a remote server with a header.

```bash
$ wormagent mcp add context7 --url https://mcp.context7.com/mcp --header CONTEXT7_API_KEY=secret
```

Authenticate with an OAuth-capable remote server.

```bash
$ wormagent mcp auth sentry
```

Remove stored OAuth credentials for a server.

```bash
$ wormagent mcp logout sentry
```

View all subcommands and flags.

```bash
$ wormagent mcp --help
```




```bash

```

```bash
$ wormagent plugin --help
```

## serve

Starts the API and web server. See [Web](/cli/web).

```bash
$ wormagent serve
```

Bind to all interfaces on a fixed port.

```bash
$ wormagent serve --hostname 0.0.0.0 --port 4096
```

Allow a browser client from another origin.

```bash
$ wormagent serve --cors https://app.example.com
```

View all subcommands and flags.

```bash
$ wormagent serve --help
```

## pair

Prints one-time links, plus a QR code of the first one, that sign a browser or
app in to the server. Links expire after 5 minutes and work once.

```bash
$ wormagent pair
```

Use an external URL in the links.

```bash
$ wormagent pair --url https://dev.example.com
```

Pair from anywhere through an OpenTunnel remote address. This exposes the
server to the internet, so the first time it enables remote access it explains
this and asks you to accept. See [Remote access](/cli/web#remote-access).

```bash
$ wormagent pair --remote
```

Accept without a prompt, for example in a script without a terminal.

```bash
$ wormagent pair --remote --yes
```

View all subcommands and flags.

```bash
$ wormagent pair --help
```

## service

Manages the background server. See [Web](/cli/web).

```bash
$ wormagent service start
```

Restart it.

```bash
$ wormagent service restart
```

Show its status.

```bash
$ wormagent service status
```

Stop it.

```bash
$ wormagent service stop
```

Read a setting.

```bash
$ wormagent service get hostname
```

Set a setting.

```bash
$ wormagent service set hostname 0.0.0.0
```

Allow an extra CORS origin.

```bash
$ wormagent service set cors https://app.example.com
```

Pass an environment variable to the server process.

```bash
$ wormagent service set env WORMAGENT_LOG_LEVEL DEBUG
```

Reset a setting to its default.

```bash
$ wormagent service unset hostname
```

View all subcommands and flags.

```bash
$ wormagent service --help
```

## reload

Reloads configuration without restarting the server. Running sessions continue with fresh services at the next step boundary.

```bash
$ wormagent reload
```

## api

Makes a request to the running server.

```bash
$ wormagent api GET /api/session
```

Call an operation ID with a query parameter.

```bash
$ wormagent api session.list --param limit=10
```

Send a JSON body.

```bash
$ wormagent api session.create --data '{"title": "New session"}'
```

Add a request header.

```bash
$ wormagent api GET /api/session -H "accept: application/json"
```

View all subcommands and flags.

```bash
$ wormagent api --help
```

## debug

Provides debugging and troubleshooting tools.

```bash
$ wormagent debug agents
```

List configuration sources.

```bash
$ wormagent debug config
```

Write a heap snapshot of the running background server and print its path.

```bash
$ wormagent debug heap-dump
```

Write the snapshot into a directory of your choice.

```bash
$ wormagent debug heap-dump --directory ./snapshots
```

Show global paths.

```bash
$ wormagent debug paths
```

Print a single path.

```bash
$ wormagent debug paths db
```

View all subcommands and flags.

```bash
$ wormagent debug --help
```

## upgrade

Upgrades WormAgent to the latest or a specific version. Alias: `update`.

```bash
$ wormagent upgrade
```

Upgrade to a specific version with a specific package manager.

```bash
$ wormagent upgrade 2.0.21 --method bun
```

View all subcommands and flags.

```bash
$ wormagent upgrade --help
```

## uninstall

Stops background services, removes the global cache, and uninstalls WormAgent. Session data, configuration, and
state are not removed.

```bash
$ wormagent uninstall
```

Preview what would be removed.

```bash
$ wormagent uninstall --dry-run
```

View all subcommands and flags.

```bash
$ wormagent uninstall --help
```
