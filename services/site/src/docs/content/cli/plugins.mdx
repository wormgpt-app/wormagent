---
title: "CLI plugins"
description: "Load TUI plugins from your WormAgent config in the CLI, and add CLI-only plugins and their options in cli.json."
---

Plugins configured in `wormagent.json(c)` that expose a TUI component are loaded automatically by the CLI. To learn how
to build plugins, see [Building plugins](/build/plugins). You do not need to add the same package to `cli.json`. The CLI
gets the active plugin list from the connected WormAgent server, so this also works when the server is remote.

Use `cli.json` for CLI-only plugins. These plugins run locally in the terminal and remain active when the CLI connects
to a remote server:

```json title="cli.json"
{
  "plugins": [
    "wormagent.example",
    "wormagent.example@1.0.0",
    "@example/wormagent-tui",
    "@example/wormagent-tui@1.0.0",
    "./plugins/status",
    "../plugins/status",
    "/home/user/plugins/status",
    "file:///home/user/plugins/status"
  ]
}
```

Entries are processed in order. Prefix an ID or wildcard with `-` to disable matching plugins:

```json title="cli.json"
{
  "plugins": ["*", "-wormagent.notifications", "-team.*"]
}
```

Pass plugin options with the object form:

```json title="cli.json"
{
  "plugins": [
    {
      "package": "@example/wormagent-tui",
      "options": {
        "compact": true
      }
    }
  ]
}
```

WormAgent also discovers plugins under the global config directory and project `.wormagent` directories. Each plugin uses
the same layout as a published package, with server and TUI entrypoints kept together.

```text title="Plugin discovery paths"
<global-config>/plugins/status/index.ts
<global-config>/plugins/status/tui.ts
<project>/.wormagent/plugins/status/index.ts
<project>/.wormagent/plugins/status/tui.ts
```

Discovered plugins can import `@wormagent/plugin/tui` directly; WormAgent resolves the package at runtime. See
[Building TUI plugins](/build/plugins/cli) for examples.
